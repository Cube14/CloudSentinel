# Cinematic editing references

[Aircord’s project gallery](https://aircord.co.jp/en/projects/) and the supplied reference recordings informed the frame scale, depth and pacing. CloudSentinel uses its own layouts, artwork, and edited footage.

| Editing idea | Original implementation |
| --- | --- |
| Anime impact cut | A narrow ice-blue directional splice on deliberate route changes. It fades immediately and leaves controls clickable. |
| Kinetic title cut | Two masked wordmark reveals on the landing frame, with a matching short reveal on destination titles. |
| Mechanical aperture | Layered vector blades and photographic metal on the access route. The composition moves between login and signup with the same media player. |
| Physical camera travel | A scroll-linked push through layered footage for Detect, Correlate and Investigate, with visible controls for direct chapter selection. |

No third-party anime scene, fan edit, music, or project footage was selected or embedded. See the [media provenance](media-licenses.md) for the footage used in the product.
